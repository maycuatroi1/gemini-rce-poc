# awesome-utils

A collection of useful utility functions for Node.js projects.

## Installation

```bash
npm install awesome-utils
```

## Usage

```javascript
const { slugify, truncate, debounce } = require('awesome-utils');

console.log(slugify('Hello World!')); // hello-world
console.log(truncate('Long text here', 8)); // Long tex...
```
